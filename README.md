# 🎂 Personalized Birthday Card

A cute, interactive birthday card web app featuring a sealed envelope, a cake with candles you can blow out, six floating lanterns with wishes, and a final surprise note!

## 🛠️ How to Customize It

To personalize this card, open the `index.html` file in any text editor (like Notepad, TextEdit, or VS Code), press **`Ctrl + F`** (or **`Cmd + F`** on Mac), and search for these placeholders to change them:

* **Search for `SENDER`**: Replace it with your name (found in the gift box section and the final letter signature).
* **Search for `RECIEVER`**: Replace it with your friend's name (found on the envelope, the title, and the top of the final letter).

Save the file, and your customized birthday card is ready to share!
