# 🎂 Personalized Birthday Card

A cute, interactive birthday card web app featuring a sealed envelope, a cake with candles you can blow out, six floating lanterns with wishes, and a final surprise note!

## 🛠️ How to Customize It

To personalize this card, open the `index.html` file in any text editor and update the names on these specific lines:

* **Line 384**: Update the sender name shown inside the little gift box preview (`- SENDER`).
* **Line 531 & 532**: Update the receiver name on the opening envelope (`For RECIEVER` and the page title).
* **Line 542**: Update the receiver name at the top of the final letter (`'RECIEVER,'`).

Save the file, and your customized birthday card is ready to share!
